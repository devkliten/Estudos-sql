# Estudos SQL - Sistema de Vendas

Repositório com scripts e consultas SQL desenvolvidos durante meus estudos de banco de dados com MySQL.

## 🗄️ Banco de dados
Sistema de vendas com 6 tabelas e 600 linhas de dados reais em português.

| Tabela | Descrição |
|---|---|
| categoria | Categorias dos produtos |
| produto | Produtos à venda |
| cliente | Clientes cadastrados |
| vendedor | Vendedores e seus cargos |
| venda | Registro de vendas realizadas |
| item_venda | Itens de cada venda |

## 📚 Tópicos praticados
- SELECT, WHERE, ORDER BY
- INNER JOIN e LEFT JOIN com múltiplas tabelas
- GROUP BY com COUNT, SUM, AVG e MAX
- HAVING para filtrar grupos
- Subqueries no WHERE e HAVING
- Anti-join com LEFT JOIN + IS NULL

## 🛠️ Tecnologia
- MySQL 8.0
- MySQL Workbench
